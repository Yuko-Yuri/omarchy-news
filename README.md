# Omarchy News

News about Omarchy, with the sources behind every claim, and the finished videos we make from it. Unofficial: made by [Parker Brown](https://x.com/parkerbrowndev) at Brown Family Sports, and not run by Omarchy or the Omacom Foundation.

**Reading with an agent?** Pull one file, a [JSON Feed](https://jsonfeed.org) that carries every story, claim and source:

```bash
curl -s https://raw.githubusercontent.com/parker-brown-family/omarchy-news/main/feed.json
```

**Checking something a video said?** Find the story below. Its file lists who made each claim, where, and how far we got in checking it. Its issue lists what is still open. Corrections are welcome there, from anyone named in a story most of all.

Each claim carries one of four marks: `read` (we read the document), `counted` (we counted or added it up), `said` (someone says so and we have not confirmed it), `open`. A story can appear under several topics, told from a different angle each time. Its claims and their marks stay the same everywhere.
